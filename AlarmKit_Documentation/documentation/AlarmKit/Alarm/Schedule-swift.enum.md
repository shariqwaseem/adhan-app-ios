# Alarm.Schedule

A list of all types of schedules that the framework supports.

```
enum Schedule
```

## Topics

### Setting an alarm schedule

[`Alarm.Schedule.Relative`](/documentation/AlarmKit/Alarm/Schedule-swift.enum/Relative)

An object that describes when an alarm alerts, relative to the device’s timezone.

[`Alarm.Schedule.fixed(_:)`](/documentation/AlarmKit/Alarm/Schedule-swift.enum/fixed(_:))

A one-shot alarm that fires at a specific time, not a time
relative to the current time zone.

[`Alarm.Schedule.relative(_:)`](/documentation/AlarmKit/Alarm/Schedule-swift.enum/relative(_:))

An alarm that can repeat and fire at a time relative to the device’s
current time zone.
