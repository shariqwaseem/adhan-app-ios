# init(alarmID:mode:)

Creates an instance of an alarm state.

```
init(alarmID: Alarm.ID, mode: AlarmPresentationState.Mode)
```

## Parameters

`alarmID`

The unique ID of the alarm.

`mode`

The mode the alarm is in such as alerting or countdown.
