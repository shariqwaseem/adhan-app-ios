# cancel(id:)

Cancels the alarm with the specified ID.

```
func cancel(id: Alarm.ID) throws
```

## Parameters

`id`

The identifier of the alarm to cancel.

## Discussion

Deletes the
alarm from the system even if the alarm has a repeating schedule.
